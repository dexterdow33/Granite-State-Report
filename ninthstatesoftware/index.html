How an app gets built

Four steps. Every app. No shortcuts.

The AI is a tool in the shop. A person decides what gets built and signs off on what leaves.

  1. Spec

    Start with a real problem and write down exactly what the app must do. No spec, no build.

  2. Build with AI

    AI coding tools write the code against that spec. A person directs the work and reads the result.

  3. The step that matters

    Test by hand

    Every feature gets run by a person on the platforms it's sold for. Anything that fails goes back to step two.

  4. Ship and fix

    It goes on sale with a version number. Bugs you report go on the list for the next release.

Why "Ninth State"

Nine made it law.

12345678NH10111213
Order of ratification9 of 13 needed

New Hampshire's vote on June 21, 1788 made it the ninth state to ratify the U.S. Constitution. Nine was the number needed for the Constitution to take effect. The software here is built in that state.

Questions

Before you buy

Straight answers. If yours isn't here, ask.

What does "built with AI" mean here?

AI coding tools write most of the code. A person writes the spec, directs the build, reviews the code, and tests the finished app before it's listed. The AI is a tool in the shop, and a person signs off on what leaves it.

How do I pay?

Each listing has a Buy button that opens a hosted checkout page run by the payment processor. Your card details go to them, not to this site.

What if an app doesn't work for me?

Get in touch with what went wrong and what you were running it on. Refund terms are shown at checkout for each app.

Do you store my data?

This website doesn't use tracking cookies or ad trackers. What each app does with data is listed on that app's page.

Can you build something for my organization?

Yes. Describe the job, the people who'll use it, and your timeline. You'll get a plain answer on whether it's a fit and what it would cost.
